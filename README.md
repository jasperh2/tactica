# Immortals Academy — Conqueror's Blade guides & tactics tools

House Immortals' member site: in-depth unit guides (149 units), hero/class guides, and
**TACTICA**, the tactics playbook tool — draw siege plans on real Conqueror's Blade maps as
keyframe playbooks, play the tween, share read-only links, export an animation package.
Plans persist in your browser (localStorage); nothing is stored server-side.

**Live:** https://jasperh2.github.io/tactica/ · tool: https://jasperh2.github.io/tactica/tactics/

Vanilla ES modules, zero dependencies, no build step. To run locally, serve the folder with
any static server (ES modules don't load over `file://`):

```sh
python -m http.server 8123
# → http://localhost:8123/
```

Note: TACTICA moved from this site's root to `/tactics/` on 2026-07-06; old `#pb=` share
links are forwarded automatically.
